# ADI Association Specification — v3.0 Draft (ITU-T Contribution)

**This branch (`v3-draft`) contains the v3.0 draft specification**, contributed to
ITU-T for Study Group review in September 2026. It supersedes the content on
`master`, which reflects the earlier v2.0 specification and Bikeshed-based build.

- **Specification:** [`spec/adia_v3.md`](spec/adia_v3.md)
- **Outstanding work:** see the Editor's Notes clause within the specification itself
- **Defect register:** [`defects/register.md`](defects/register.md)
- **Working locally:** see [`WORKING_LOCALLY.md`](WORKING_LOCALLY.md) and [`CHEAT_SHEET.md`](CHEAT_SHEET.md)

## Status

This is a working draft under active review. Automated consistency checks run
locally (`make status`) and are summarized in the specification's own
Editor's Notes clause, which is regenerated from the defect register on every
save.

## Previous version

The v2.0 specification and its Bikeshed build system remain on the `master`
branch for historical reference.
