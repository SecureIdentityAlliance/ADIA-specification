# ADIA Logo Assets

Official ADIA logo files, for use in presentations, web pages, and other
project materials.

## `online/` — screen and web use
Includes both `.ai` (vector source) and `.png` (2128×1633, transparent
background) for each variant. Use the PNGs directly for slides, web pages,
or anywhere a raster image is sufficient. Use the `.ai` files if you need to
edit or re-export at a different size.

## `print/` — print production
Vector `.ai` source only, intended for professional print workflows
(business cards, banners, printed reports). Hand these to a printer or
designer rather than the online set.

## Variants (both folders)
| File | Use |
|---|---|
| `logo_ADIA_RVB` | Full-color version (blue + dark). Default choice; use on white or light backgrounds. |
| `logo_ADIA_black` | Single-color black. For light backgrounds where color reproduction isn't available (e.g. black-and-white printing, faxes, single-color letterhead). |
| `logo_ADIA_white` | Single-color white. For dark or colored backgrounds. |

The RGB SVG version used in the specification document itself
(`spec/figures/adia-logo.svg`) was converted from `online/logo_ADIA_RVB.ai`.
